# Future Research

This folder contains future research directions. These documents are proposals and roadmap notes, not validated claims.

Begin with `roadmap.md`.

## Representational freezing

A new institutional extension of the programme is documented in [`../FROZEN_REPRESENTATIONS.md`](../FROZEN_REPRESENTATIONS.md).

It asks what happens when a representation was historically useful but the task, environment, or system changes faster than the institution using it.

The central hypothesis is deliberately provisional:

> **Institutions can freeze representations and continue using them after they cease to be causally sufficient for the task.**

The note distinguishes this institutional hypothesis from the core scientific claim of task-relative causal sufficiency and proposes falsification conditions rather than assuming institutional ontology failure by default.
